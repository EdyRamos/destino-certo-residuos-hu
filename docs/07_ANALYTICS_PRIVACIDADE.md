# 07 - Analytics e Privacidade

## V1
Sem analytics externo e sem login obrigatório.

## Dados locais sugeridos
Guardar apenas:
- data/hora da sessão;
- nível;
- total de perguntas;
- acertos;
- erros;
- pontos;
- categorias com erro.

## Não guardar
- nome de paciente;
- prontuário;
- informação clínica;
- credenciais;
- dados pessoais desnecessários.

## Identificação do aluno
Se futuramente o hospital quiser registrar presença, implementar como módulo separado e aprovado. Não misturar isso na V1 do jogo.

## Exportação
Para homologação, permitir exportar localmente CSV/JSON das sessões. O usuário decide quando compartilhar o arquivo.
