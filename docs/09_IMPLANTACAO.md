# 09 - Implantação

## Opção recomendada para piloto
Hospedagem estática HTTPS gratuita ou infraestrutura institucional já disponível.

Exemplos compatíveis:
- Cloudflare Pages;
- GitHub Pages;
- servidor estático do hospital.

## Piloto
1. publicar versão `0.9.0-homolog`;
2. abrir no tablet conectado à rede;
3. confirmar banner/status `Pronto para uso offline`;
4. instalar na tela inicial;
5. desligar Wi-Fi;
6. fechar e abrir o app;
7. executar uma sessão completa;
8. validar áudio, touch e orientação;
9. coletar feedback;
10. liberar `1.0.0` após aprovação de conteúdo.

## Tablet compartilhado
No modo de treinamento em grupo:
- botão `Nova sessão` deve limpar apenas pontuação da partida, não configurações;
- histórico pode ter botão `Limpar histórico local`;
- não exigir conta do usuário.

## Se a política do dispositivo bloquear PWA
Plano B futuro: empacotar a mesma aplicação com Capacitor/TWA. Não fazer isso antes de confirmar necessidade.
