# 11 - Checklist de Validação pela DEP

Responsável sugerido: Patricia Ito / Divisão de Ensino e Pesquisa, com participação do responsável institucional pelo gerenciamento de resíduos.

Para cada item do CSV, revisar:
- [ ] nome está correto;
- [ ] destino está correto;
- [ ] condição do item está clara (com sangue, sem sangue, vazio, com resto etc.);
- [ ] explicação está correta e suficientemente curta;
- [ ] imagem final representa o item sem ambiguidade;
- [ ] não há regra institucional faltando;
- [ ] não há classificação duplicada/contraditória.

## Validação visual
Também aprovar:
- nomes dos recipientes;
- cores e símbolos;
- formato do coletor de perfurocortantes;
- aparência do hamper;
- representação de frasco-ampola vazio x químico.

## Fechamento
Quando aprovado:
1. atualizar conteúdo;
2. definir `requiresInstitutionalValidation=false`;
3. registrar versão e data;
4. gerar build de produção.
